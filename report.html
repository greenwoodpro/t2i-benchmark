05 — Report

两张卡上的十三个配置

Tesla T4（16G）与 NVIDIA A10（24G）· 13 个开源模型配置 · 723 张有效图 · 每张图 32 项参数完整留痕。本文回答三个工程问题：16G 显存下哪些模型真的可用、 速度与显存的边界在哪、不同架构家族的差异在哪。

01

方法与口径

所有模型用各自官方推荐参数，不统一改写、不加 LoRA、不开提示词增强。

项做法
硬件T4 16G（Turing，无 bf16 / fp8 原生加速）· A10 24G（Ampere，原生 bf16）
运行方式ComfyUI + HTTP API 串行批处理；单模型连续跑完再切换，减少权重重载
T4 定版参数--fp16-unet --lowvram --reserve-vram 0.5 --disable-cuda-malloc
计时提交 prompt → 取回图片字节的墙钟时间，含文本编码与 VAE 解码；首张标记 cold_start
显存独立线程每 0.5 秒采样 nvidia-smi memory.used，取峰值
记录records.jsonl（32 字段）+ records.csv + PNG 内嵌 JSON，三层可追溯
容错断点续跑以「记录 + 图片同时存在」判定；失败记录隔离，不进入统计
两个中位数的区别。「定版中位」取该模型最近一个运行批次，同批启动参数一致； 「全量中位」把历史上所有批次混在一起，会把早期用旧参数的慢速结果算进去。 跨版本比较请用定版中位，复核历史请用全量中位。

03

生成总耗时

累计墙钟时间，按显卡与模型拆开。含首张的模型加载，所以比「中位 × 张数」略高。

堆叠条按模型累计耗时排序，悬停看具体数值。时间线是每个运行批次的出图张数： 10-17 起步、10-18 T4 首轮、10-20 A10 阶段、10-22 换定版参数、10-27 补测。

04

T4：16G 的真实边界

六个配置全部跑满 51 条 SFW，无空白图、无缺图。

模型步数 / CFG采样器定版中位全量中位P90累计峰值显存图数

显存不是「够用」，是「刚好」

FLUX.2 klein 4B、Z-Image Turbo、FLUX.1 Krea 三个模型的峰值都在 14901–14907 MB， 而 T4 可用显存 15360 MB，只剩 400–500 MB。此时 ComfyUI 必须把权重分块换入换出， PCIe 带宽成为隐性瓶颈——这是 Krea 单张 111 秒的主因，而不是算力不足。

一个启动参数带来 20–70% 提速

去掉 --disable-smart-memory 后，权重在同模型连续跑时常驻显存： FLUX.2 klein 4B 从 43.4 秒降到 13.1 秒（3.3 倍），Z-Image 68.2 → 51.4 秒，WAI 27.2 → 28.1 秒（基本持平）。 对照实验显示 --reserve-vram 1.5 与 0.5、以及是否加 --lowvram 对速度没有影响（41.4 秒 vs 41.4 秒）， 说明瓶颈在分块与算力，不在分配策略。

05

A10：买到的是容量

七个配置，包括 T4 根本起不来的 20B 级模型与 50 步基线。

模型步数 / CFG采样器定版中位全量中位P90累计峰值显存图数
MOSS 三个配置不要混算。 50 步基线用真 CFG（cfg 3.0）、单张约 197 秒；两个 8 步 DMD 加速档无 CFG、约 18 秒。 加速档里 moss_image_base_fast 用的是 Base 权重，与 SFT 版不是同一个底模。

07

稳定性与已知崩溃

出图完整性

  • T4 有效图 366 张，A10 357 张，合计 723
  • 空白图 0，缺图 0，记录与图片 1:1
  • 失败记录隔离在 records_failed_quarantine.jsonl

两个真问题

  • SDXL CLIP 边界：negative 超过 77 token（约 300 字符）必崩 cublasSgemm， 与语义无关；用「末尾逐段裁词重试」规避，年龄护栏词在开头不受影响。
  • FLUX.3 在 T4 全黑：bf16 转 fp16 计算时数值溢出，产出纯黑图； int8 权重在 Turing 上无原生算子。最终改为 A10 原生 bf16 重跑。

完整事故链与修复过程见 docs/CHANGELOG.md， 共 19 条偏离记录，包括一次 CUBLAS 错误污染 CUDA context 导致后续 61 条连锁失败。

09

结论

T4 通用首选

FLUX.2 klein 4B

4 步、定版中位 13.1 秒、显存可承载。代价是贴顶，必须 lowvram。

中文与文字渲染

Z-Image Turbo / Qwen-Image 2.1 Turbo

T4 用 Z-Image（8 步 51.4 秒）；有 24G 卡就用 Qwen Turbo（8 步 24.1 秒），中文排版更稳。

极致速度

FLUX.3 klein（A10）/ FLUX.2 klein（T4）

A10 上 16 步 13.0 秒；T4 上 4 步 13.1 秒。两者在各自卡上都是最快。

布局可控

MOSS-Image

50 步单张约 197 秒，只适合小批量出图；做版面实验可以，不适合批量生产。
